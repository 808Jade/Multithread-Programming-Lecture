# 멀티쓰레드 프로그레밍

- bakery 알고리즘
- peterson 알고리즘
- CAS
- 성긴동기화
- 세밀한동기화
- 낙천적인동기화
- 게으른동기화
- 비멈춤동기화
- EBR

병렬 처리 자료구조 구현: Stack, Queue, Set, SkipList를 멀티쓰레드 환경에 맞춰 설계하고 성능을 측정.

고성능 동시성 제어: 병목 현상을 최소화하기 위해 Mutex 기반의 동기화를 넘어, Lock-free 알고리즘을 적용한 고성능 멀티쓰레딩 기법을 구현.

C++ Thread API 활용: 다양한 동기화 객체 및 쓰레드 API 사용.
